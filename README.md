## Instalación

1. **Clonar o descargar el repositorio:**
   ```bash
   git clone https://github.com/mchena6/calculadora_zona_fresnel.git
   cd calculadora_zona_fresnel
   ```

2. **Crear entorno virtual y activarlo:**
   ```bash
    python -m venv venv
    source venv_bin/activate
   ```
   
3. **Instalar dependencias:**
   ```bash
    pip install requirements.txt
   ```
   
4. **Ejecutar programa:**
   ```bash
    python python calculadora_zona_de_fresnel_chena_martin.py
   ```
